# Sathish Sivakumar — Engineering Portfolio

A responsive, dark, glassmorphism static portfolio for Technical Lead / Full-Stack Developer positioning.

## Run locally
Open `index.html` directly in a browser, or use any static server.

Example:
```bash
python3 -m http.server 8000
```
Then visit `http://localhost:8000`.

## Deploy
Upload the folder to GitHub Pages, Netlify, Vercel, Firebase Hosting, or any static hosting provider.

## Resume
Place the supplied PDF at:
`assets/SATHISH_SIVAKUMAR_Resume.pdf`
